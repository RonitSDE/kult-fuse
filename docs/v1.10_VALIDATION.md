# KULT Fuse v1.10.0 — validation and release decision

**Build type:** Devnet integration candidate; final competition-proof release still pending.

## Completed in this environment

- Existing 92 JavaScript unit tests plus 9 new Kalshi/reference and evidence-journal tests: **101/101 passed**.
- New read-only Kalshi observer tests exercise response parsing, YES/NO book, ticker/path validation, caching, error handling, and divergence warnings.
- Browser UI via Chromium using an in-memory synthetic fixture: desktop 1440px and mobile 390px passed interaction checks, including the four-step walkthrough, source-label consistency and journal filters. No page errors or horizontal overflow detected. It was a synthetic browser test, **not a live internet/site test**.
- Mock preview HTTP routes `/api/market/context` and `/api/journal` returned successful JSON responses. The actual live RPC/Kalshi/Velocity integration has not been exercised.
- Source integrity regenerated and SHA-256 verified; packaged archive checked.

## Explicit failures / external gates

- This container runs **Node 22**, while package requires **Node 24**. No independently green networked `npm ci` on the release SHA here.
- Foundry/Anchor/Solana/Velocity devnet tooling, deployment keys and a live market aren't available here. The Anchor build, public devnet deployment, authentic Velocity open/resize/close receipts and zero residual position proof **remain unverified**.
- `npm run preflight` correctly fails for absent program ID/IDL, RPC, venue wallet, owner/oracle/executor keys, real market mint, CI tag/SHA, and Node 24.
- `npm run submission:check` correctly fails for missing public URL, video, current contract and venue signatures, live fill anchors and independent verifier run.
- The worker-held Velocity key can bypass Fuse. This is a documented security limitation and a **real-money mainnet blocker**.

## Devnet release decision

**Proceed to controlled Solana devnet deployment/integration only.** Do not mark the hackathon submission verified until the exact SHA has live onchain mandate and Velocity proofs, a green build, a stable public URL and a video recorded against that release.
